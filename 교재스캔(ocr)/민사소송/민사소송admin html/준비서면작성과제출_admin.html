준비서면 작성과 제출

민사소송법 제272조~제279조 / 법무사 업무: 준비서면 작성·제출 대행 (핵심 업무)
사건유형: 민사소송 모든 단계 관할: 수소법원 근거법령: 민사소송법 제272조~제279조 당사자: 원고·피고 핵심기간: 변론기일 5일 전 제출 권장

0⚠️ 법무사 업무범위 · 수임 판단

업무범위 한계

  • 가능: 준비서면 작성·제출 대행 (법무사 핵심 업무), 답변서·반소장 외의 서면작성, 증거목록 작성, 전자소송 파일 업로드
  • 불가(변호사법 위반): 준비서면에 담을 법리 판단·소송전략 조언, 상대방 준비서면의 법률적 반박 방향 제시, 법정 대리

수임 판단 포인트

  • 의뢰인으로부터 사실관계만 수령 후 서면 형식으로 정리 — 법리 판단은 의뢰인이 제공한 사실에 기반
  • 변론준비절차 회부 사건 — 준비서면 교환 방식으로 진행됨
  • 상대방 준비서면에 대한 반박 내용은 의뢰인이 직접 제공해야 함

받지 말아야 할 신호 체크리스트

  • "어떤 내용을 주장해야 이기나요?" — 법률 조언 요구
  • "상대방 주장의 문제점을 찾아주세요" — 법리 분석 요구
  • 법원 석명사항에 대한 법률적 답변 작성 요구

1핵심쟁점

실체적 쟁점 — 준비서면의 법적 성격

  • 진술 전치 효과: 준비서면은 변론기일에서의 진술을 예고하는 것 — 변론기일에서 반드시 진술해야 재판자료가 됨 (민소 §134①, §272)
  • 실권효 위험: 변론준비기일 이후 새로운 공격방어방법은 원칙적으로 제출 불가 (민소 §285)
  • 적시제출주의: 공격방어방법은 소송 진행 정도에 따라 적절한 시기에 제출 필요 (민소 §146)

절차적 쟁점 (결정적 체크포인트)

구분내용주의사항
제출 기한변론기일 5일 전 (권고)늦은 제출 시 법원 제지 가능
상대방 열람전자소송 시스템으로 자동 열람 가능지면 제출 시 부본 별도 필요
변론준비절차서면에 의한 준비절차 — 당사자 준비서면 교환결과를 변론기일에서 진술해야 효력 발생
실권효변론준비기일 종결 후 새로운 공격방어방법 제출 불가 원칙민소 §285, 예외: 故意·重過失 없이 제출 못한 경우

2업무 절차 흐름

의뢰인으로부터 사실관계 확인

상대방 준비서면 내용, 반박할 사실관계, 추가 주장 사항을 의뢰인에게 서면으로 제공받음.

💡 실무 TIP: 의뢰인이 제공한 사실관계를 그대로 정리하는 것이 법무사 역할 — 법리 방향 제시 금지

준비서면 양식 작성

사건번호, 당사자 표시 정확히 기재. 사실 주장은 항목별로 구분하여 명확하게 작성. 첨부 서증 목록 포함.

전자소송 제출 또는 법원 접수

전자소송(ecfs.scourt.go.kr)으로 업로드. 지면 제출 시 법원 접수처에 원본 + 상대방 수 부본 함께 제출.

💡 실무 TIP: 전자소송 제출 시 접수 영수증 저장 — 제출 시각 확인 가능

변론기일 진술 안내

의뢰인(또는 대리인)에게 변론기일에 준비서면 내용을 진술해야 효력 발생함을 안내.

다음 기일 준비서면 여부 확인

다음 변론기일 전 추가 준비서면 필요 여부 의뢰인에게 확인. 증거신청 필요 시 별도 작성.

6법무사 실무 노하우

💡 실무 TIP 모음

  • 준비서면 작성 시 사실 주장은 번호를 매겨 정리 — 법원이 보기 쉬운 형식으로
  • 변론준비절차 중인 사건은 실권효 예방을 위해 모든 주장·증거를 조기에 망라하여 제출
  • 전자소송 제출 후 접수 확인 메시지 스크린샷 보관 (제출기한 분쟁 예방)
  • 상대방 준비서면 수령 즉시 의뢰인에게 전달 — 반박 사실관계 제공 요청
  • 준비서면에 서증 첨부 시 갑/을 제○호증 번호를 준비서면 본문에 명시
📝 현장 메모 [직접 추가]

자주 사용하는 준비서면 문구 템플릿, 재판부별 선호 형식, 특이 사항 등을 기록하세요.




7주의사항 & 사고 · 실수 사례

⚡ 기간도과 위험

  • 실권효: 변론준비기일 종결 후 새로운 공격방어방법 제출 원칙 불가 — 사전에 모든 주장 망라 필수
  • 기일 5일 전 제출 미준수: 법원이 해당 기일 심리 거부 가능

흔한 실수

  • 준비서면에 기재하고 변론기일에서 진술하지 않음 — 재판자료 불인정
  • 서증 첨부 시 갑/을 번호 혼동
  • 전자소송 제출 후 접수 완료 확인 미실시 — 기술적 오류로 미접수 가능
  • 상대방 준비서면 열람 지연 — 반박서면 준비 기간 부족

변호사법 경계선

  • 준비서면에 담을 법리 주장 직접 작성 — 사실관계 정리 수준 초과 시 법률 조언에 해당
