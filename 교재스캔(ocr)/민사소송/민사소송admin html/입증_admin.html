입증 — 증거조사 & 증인신문

민사소송법 제280조~제332조 / 법무사 업무: 증거신청서·증인신청서 작성·제출 대행
사건유형: 민사소송 증거조사 단계 관할: 수소법원 근거법령: 민사소송법 제280조~제332조 당사자: 원고·피고 (증인: 제3자) 핵심: 증명책임·자유심증주의

0⚠️ 법무사 업무범위 · 수임 판단

업무범위 한계

  • 가능: 증거신청서 작성·제출 대행, 증인신청서 작성, 서증 목록 작성, 증거보전신청서 작성, 문서제출명령 신청서 작성
  • 불가(변호사법 위반): 증인신문 직접 실시, 반대신문 방향 법률 조언, 증거의 법적 가치 판단, 증명책임 분배 분석

수임 판단 포인트

  • 증인신청은 이름·주소·연락처·직업·당사자와의 관계·증명취지를 의뢰인이 제공해야 함
  • 증거보전이 필요한 경우 — 소 제기 전도 가능 (민소 §375)
  • 문서제출명령 신청 — 상대방 보유 문서 확보 시 활용

받지 말아야 할 신호 체크리스트

  • "증인을 어떻게 신문해야 하나요?" — 법률 조언 요구
  • "이 증거가 유리한지 판단해주세요" — 증거의 법적 가치 판단 요구
  • "상대방 증인을 어떻게 반박하나요?" — 소송전략 요구

1핵심쟁점

실체적 쟁점

  • 증거능력 vs 증거력: 증거능력 = 증거조사 대상이 될 수 있는 자격 / 증거력(증명력) = 사실인정에 기여하는 정도 — 양자 구별 필수
  • 자유심증주의(민소 §202): 법관은 변론 전체의 취지와 증거조사 결과를 자유로운 심증으로 판단
  • 증명 vs 소명: 증명 = 법관 확신, 소명 = 개연성 정도 — 보전처분 등에서 소명으로 足
  • 불법감청 녹음: 상대방 동의 없는 전화 통화 녹음 — 통신비밀보호법 §3①, §4 위반으로 증거능력 없음 (대법원 2021다236999)

증거방법별 특징 비교

증거방법특징신청 방법주의사항
서증문서의 의미내용이 증거자료갑/을 제○호증 제출진정성립 필요 — 상대방 부인 시 증명 필요
증인제3자의 경험사실 진술증인신청서 제출당사자·법정대리인은 증인 불가 (당사자신문으로)
감정전문가 판단·의견 보고감정신청서 제출감정인은 법원이 지정, 대체성 있음
검증법원이 직접 오관으로 확인검증신청서 제출현장검증은 기일 지정 필요
당사자신문당사자·법정대리인 진술신청서 제출증거능력 제한, 증인신문 규정 일부 준용

2업무 절차 흐름

증명 필요 사실 파악 (의뢰인 제공)

의뢰인으로부터 증명이 필요한 사실관계와 보유 증거 목록을 제공받음. 서증·증인·감정 여부 결정은 의뢰인(또는 변호사) 판단.

증거신청서 작성

증거방법(증인, 감정, 검증 등)과 증명취지 명시. 서증은 갑/을 번호 부여 후 목록 첨부.

💡 실무 TIP: 증인신청서에는 증인 이름·주소·연락처·직업·당사자와의 관계·증명취지를 구체적으로 기재 (민소규 §75②)

전자소송으로 제출

서증 사본을 PDF로 변환 후 전자소송 업로드. 지면 제출 시 원본과 부본 준비.

문서제출명령 신청 (필요 시)

상대방이나 제3자가 보유한 문서가 필요한 경우 문서제출명령 신청서 작성·제출. 제출의무 예외 사유 확인 (민소 §344).

증거보전 신청 (소 제기 전/후)

증거 멸실 위험 시 증거보전신청 가능 (소 제기 전 포함). 관할법원 또는 증거 소재지 지방법원에 신청 (민소 §375).

6법무사 실무 노하우

💡 실무 TIP 모음

  • 증거는 쟁점정리기일 이전에 집중 제출 — 집중증거조사 원칙 (민소 §293)
  • 소명자료로 제출 시 "소갑 제○호증" 표시 — 증명과 소명 구분 철저
  • 감정신청 전 감정비용 예납 가능 여부 의뢰인 확인 필수 (비용 미납 시 신청 취하)
  • 문서제출명령 — 상대방 제출 거부 시 법원이 그 문서 취지를 사실로 인정 가능 (민소 §349)
  • 증거보전은 소 제기 전에도 가능 — 멸실 위험 있는 증거 조기 확보 전략

7주의사항 & 사고 · 실수 사례

⚡ 기간도과 위험

  • 증거 적시 미제출: 변론준비절차 종결 후 신규 증거신청 실권효
  • 감정비용 미예납: 예납 기간 내 미납 시 감정신청 취소 가능

흔한 실수

  • 서증목록에 갑/을 번호 혼동 — 원고는 甲(갑), 피고는 乙(을)
  • 당사자를 증인으로 신청 — 당사자신문 신청으로 변경 필요
  • 감정신청 시 감정사항을 너무 막연하게 기재 — 법원이 보완 요구

변호사법 경계선

  • 증인 신문 사항 직접 작성 — 법리 판단·소송전략에 해당
  • 증거 가치 평가 및 유불리 판단 제공 — 법률 조언에 해당
