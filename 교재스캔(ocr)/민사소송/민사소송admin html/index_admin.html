민사소송 실무 직원용 Admin

법무사 사무소 직원이 민사소송 사건을 정확하고 효율적으로 처리하기 위한 내부 실무 지원 페이지 전체 목차입니다.
각 페이지는 핵심쟁점·업무절차·첨부서류·비용산정·법무사 노하우를 집약하고 있습니다.

⚠️ 이 페이지 모음은 대외 배포 금지입니다

⚠️ 모든 사건에 공통 적용 — 법무사 업무범위 한계

  • 법무사는 소송대리권이 없습니다. 서류 작성·제출 대행만 가능하며, 법정 대리·변론·교섭은 변호사법 위반 소지.
  • 의뢰인 앞에서 "승소 가능성"을 단정하거나, 상대방과 직접 교섭·협상하지 않습니다.
  • 소멸시효·제소기간 도과 여부를 먼저 확인하고, 실익 없는 사건은 수임 전 명확히 설명합니다.
  • 변호사 연계가 필요한 사건(법률판단이 복잡한 사건, 고액 청구, 기업 분쟁 등)은 사전에 협력 변호사를 소개합니다.
