독촉절차 (지급명령 · 이의 후 소송이행)

민사소송법 제462조~제474조 / 법무사 업무: 지급명령신청서·이의신청서 작성·제출 대행, 인지보정 대행
사건유형: 금전 등 지급 청구 특별절차 관할: 채무자 주소지 지방법원 (의무이행지 등 특별재판적 가능) 근거법령: 민소 §462~§474 / 소촉법 §20의2 담당: 사법보좌관 (이의신청 전), 판사 (이의신청 후) 핵심기간: 채무자 이의신청 2주 (불변기간)

0⚠️ 법무사 업무범위 · 수임 판단

업무범위 한계

  • 가능: 지급명령신청서 작성·제출 대행, 이의신청서 작성·제출 대행, 인지·송달료 납부 대행, 이의 후 소송이행 시 인지보정 대행, 강제집행신청서 작성 대행
  • 불가(변호사법 위반): 이의 후 소송에서 변론 대리, 지급명령 발령 가능성 법리 판단, 소송 전략 수립

수임 판단 포인트

  • 청구 종류 확인: 금전·대체물·유가증권 지급 청구에 한함 (권리 확인·이전 청구 불가)
  • 채무자 주소 확인: 주소 불명 시 원칙적으로 독촉절차 불가 (소촉법 §20의2 예외 존재)
  • 이의신청 의뢰 시: 지급명령 송달일 + 14일 이내인지 즉시 확인
  • 채무자가 이의할 가능성이 높은 사건: 처음부터 소 제기 권유 검토

받지 말아야 할 신호 체크리스트

  • 이의신청 기간(2주) 도과한 채무자 측 의뢰
  • 금전청구가 아닌 사건 (부동산인도, 소유권이전등기 등)
  • 이의 후 소송에서 법리 판단·변론 대리 요청
  • 인지보정 기간 도과 후 각하된 사건의 소 제기 대행 (새로운 소 제기로 처리해야 함)

1핵심쟁점

독촉절차 vs 소 제기 — 수임 시 판단 기준

항목독촉절차 (지급명령)정식 소 제기
초기 인지소장 인지의 1/10전액
채무자 이의 시나머지 9/10 보정 + 송달료 추가추가 비용 없음
채무자 주소 불명원칙적 불가 (예외: 소촉법)공시송달 가능
적합 사건채무 인정, 이의 가능성 낮음다툼 예상, 복잡한 사건
기판력없음 (청구이의의 소로 다툴 수 있음)있음

이의 후 인지보정 — 핵심 업무 포인트

  • 채무자 이의 → 지급명령 실효 → 소송절차로 이행
  • 법원이 채권자에게 인지보정명령 발령 → 정해진 기간 안에 납부 필수
  • 보정액 = 소장 기준 인지 전액 - 이미 납부한 1/10 인지
  • 보정 미이행 → 지급명령신청서 각하 (즉시항고 가능)
  • 실무상 인지보정명령과 송달료납부명령이 동시에 발령됨

절차적 체크포인트

단계기간/조건미준수 결과
채무자 이의신청송달일로부터 2주 (불변기간)지급명령 확정, 강제집행 당함
채권자 인지보정보정명령 수령 후 법원 지정 기간 내지급명령신청서 각하
채권자 송달료 추가납부인지보정과 동시 (동반명령)각하 위험

2업무 절차 흐름

① 채권자 측 — 지급명령 신청부터 집행까지

관할 확인 → 지급명령신청서 작성

채무자 주소지 지방법원이 원칙. 의무이행지(금전채무 → 채권자 주소지), 근무지·거소지 등 특별재판적도 가능. 전자독촉(전자소송포털)으로도 제출 가능, 법무사 제출대행 권한 확인 필요.

인지·송달료 납부 (소장 인지의 1/10)

지급명령신청 인지 = 소장 인지의 10분의 1. 송달료 예납. 전자독촉 시 온라인 납부. 전산양식 A2342~A2347 표준양식 활용.

💡 실무 TIP: 채무자 이의 가능성이 높다고 판단되면 의뢰인에게 처음부터 소 제기를 권유. 이의 시 나머지 9/10 인지 추가 부담이 발생함을 미리 설명.

법원 심사 → 지급명령 발령 → 양쪽 당사자에게 송달

법원이 채무자를 심문하지 않고 서면심사만으로 발령. 채무자에게 적법하게 송달되어야 효력 발생. 채무자 주소 불명 시 소송절차로 회부 (원칙, 은행 등 예외).

[이의 없음] 2주 경과 → 확정 → 강제집행

확정 시 집행력 발생. 집행문 없이 지급명령 정본으로 강제집행 신청. 단기소멸시효 채권도 10년으로 연장 (민법 §165). 단, 기판력은 없음.

[이의 있음] 인지보정명령 수령 → 기간 내 납부 → 소송이행

보정할 인지 = 소장 기준 인지 전액 - 이미 납부한 1/10. 송달료도 추가 납부. 납부 완료 후 사건기록이 관할법원(합의부 사건이면 합의부)으로 송부 → 정식 재판.

② 채무자 측 — 이의신청 실무

지급명령 수령 → 2주 이내 이의신청

지급명령서 수령일 다음 날부터 14일 계산. 이의신청서에 "지급명령에 응할 수 없다"는 취지만 기재. 구체적 이유·증거 불필요. 인지·송달료 불필요. 편지·구두 등 불복 취지가 있으면 이의로 처리.

이의신청 제출처 및 기한의 이익

발령 법원(독촉법원)에 제출. 기간 경과 후 이의는 부적법 각하. 책임질 수 없는 사유로 기간 놓쳤으면 그 사유 소멸 후 2주 내 추후보완 이의 가능.

이의 후 → 소송에서 방어 준비

지급명령 신청 시를 소 제기 시점으로 보므로 청구원인은 신청서를 인용해 진술. 이후 일반 소송 절차로 진행. 답변서 제출 및 증거 준비.

3첨부서류

서류명필수/선택법령근거발급처유효기간실무 비고

4비용 · 소가 산정

인지 계산 공식

단계납부 인지계산 기준
지급명령신청 시소장 인지의 1/10청구금액(지급명령 신청금액) 기준 소가로 소장 인지 계산 후 1/10
이의 후 소송이행 시 보정소장 인지 전액 - 이미 납부한 1/10지급명령 신청 시 청구금액이 소가로 확정됨

계산 프로그램: 대법원 인지계산기 (나의사건검색 → 민사 인지계산) 활용

소가 1억 이하: 소가×0.5% + 5,000원 / 1억~10억: 소가×0.45% + 5,500원 / 10억 초과: 소가×0.4% + 55,500원

이의 후 합의부로 이송 시 인지 주의

지급명령 청구금액이 2억 원 초과인 경우 이의 후 소송이행 시 지방법원 합의부 또는 고등법원 관할. 인지보정 완료 후 기록이 관할법원으로 송부됨. 합의부 사건 여부에 따라 소송 진행 방식 변경.

주요 판례

대법원 2009다39530 — 단기소멸시효 채권도 지급명령으로 확정되면 소멸시효 10년으로 연장.

대법원 2006다73966 — 확정된 지급명령에는 기판력 없음. 채무자는 발령 전 사유로도 청구이의의 소 가능.

대법원 2024마5496 — 지급명령 송달 전에 한 이의신청은 부적법하나, 이후 적법한 송달 시 흠 치유됨.

6법무사 실무 노하우

💡 이의 발생 즉시 인지보정 캘린더 등록

  • 채무자 이의신청 통보를 받는 즉시: 법원 인지보정명령 수령 예정일을 캘린더에 기재
  • 인지보정명령 수령 당일: 보정 마감일 계산, 의뢰인에게 즉시 연락
  • 보정 금액 = (소가 기준 소장 인지 전액) - (이미 납부한 1/10 인지)
  • 송달료도 동시에 추가납부 — 빠짐없이 확인

💡 채무자 주소 불명 사전 확인

  • 신청 전에 채무자 주민등록 주소 조회 (의뢰인 통해 확인)
  • 주소 불명이면: 처음부터 소 제기 + 공시송달 방향으로 전환 안내
  • 은행·금융기관 채권자는 소촉법 §20의2 예외 적용 가능 — 개인 채권자는 원칙적 불가

💡 전자독촉 실무 포인트

  • 전자소송포털에서 전자독촉 신청 시 자동으로 채무자 주소지 관할법원으로 접수
  • 인지·송달료 온라인 납부, 부본 제출 불필요
  • 사법보좌관이 처리 (이의신청 전까지)
  • 이의 후: 판사 담당, 기록이 관할 합의부 또는 단독에 배당

7주의사항 & 사고 · 실수 사례

⚡ 기간 도과 위험

  • 채무자 이의신청 기간 도과 → 지급명령 확정 → 뒤늦게 이의 각하 (추후보완 요건 엄격)
  • 채권자 인지보정 기간 도과 → 신청서 각하 → 새로 소 제기해야 함 (시효 문제 발생 가능)
  • 법원 보정명령 수령 즉시 날짜 계산하지 않으면 기간 놓침

흔한 실수

  • 인지 1/10 계산 오류: 소가를 잘못 산정해 인지 부족 → 보정명령 후 각하 위험
  • 이의신청서를 독촉법원이 아닌 다른 법원에 제출
  • 인지는 납부했으나 송달료 추가납부를 빠뜨림 (동반명령 확인 필요)
  • 채무자 주소 불명 사건을 독촉절차로 신청해 소송회부 후 인지 추가 부담
  • 이의 후 소송이행 사실을 의뢰인에게 즉시 알리지 않아 대응 지연

변호사법 경계선

  • 이의 후 소송에서 변론기일 출석·발언 → 변호사법 위반
  • 지급명령 청구금액의 법리적 타당성 판단 → 변호사 영역
  • 이의신청 후 소송 전략·증거 전략 수립 → 변호사 영역
  • 법무사 가능 범위: 신청서 작성, 인지·송달료 계산·납부, 인지보정서 작성·제출
