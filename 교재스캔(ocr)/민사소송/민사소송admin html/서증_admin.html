서증 (書證)

민사소송법 제343조~제362조, 민사소송규칙 제107조 이하 / 법무사 업무: 서증목록 작성·제출 대행
사건유형: 민사소송 증거조사 단계 관할: 수소법원 근거법령: 민사소송법 제343조~제362조 당사자: 원고(甲)·피고(乙) 핵심: 진정성립·형식적 증거력·처분문서

0⚠️ 법무사 업무범위 · 수임 판단

업무범위 한계

  • 가능: 서증목록 작성·제출 대행, 서증 분류·번호 부여, 공문서·사문서 구분 정리, 문서제출명령 신청서 작성, 문서송부촉탁 신청서 작성
  • 불가(변호사법 위반): 서증의 법적 가치(증거력) 판단, 처분문서/보고문서 구별에 따른 증거 전략 수립, 진정성립 다툼 방법 법률 조언

수임 판단 포인트

  • 의뢰인이 보유한 문서 목록을 먼저 파악하여 서증 분류 진행
  • 공문서(주민등록등본·등기부등본 등)는 진정성립이 추정됨
  • 사문서는 상대방이 진정성립 다투면 증명 필요 — 필적 감정 등 추가 절차 요

받지 말아야 할 신호 체크리스트

  • "이 계약서가 유리한지 판단해주세요" — 법률 판단 요구
  • "상대방 서증을 어떻게 반박하나요?" — 소송전략 요구
  • 서증 위조·변조 의혹 확인 요청 — 전문가(필적감정 등) 연결

1핵심쟁점

실체적 쟁점 — 서증의 증거력 판단 구조

  • 형식적 증거력(진정성립): 문서가 작성자로 주장되는 자의 의사에 의하여 작성되었음이 인정되는 것 — 진정성립 미인정 시 실질적 증거력 판단 불필요
  • 실질적 증거력: 진정성립이 인정된 후, 요증사실 인정에 얼마나 기여하는지 — 자유심증으로 판단
  • 처분문서 vs 보고문서: 처분문서(계약서·어음 등) — 진정성립 인정되면 법률행위 존재 증명됨 / 보고문서(영수증·일기 등) — 진정성립 인정되어도 내용의 진실 여부는 별도 판단 필요

문서 종류별 진정성립 추정 여부

2업무 절차 흐름

의뢰인 보유 문서 목록 수령

의뢰인으로부터 제출할 문서 목록과 실물(또는 사본) 수령. 공문서/사문서, 원본/사본 구분.

서증 번호 부여 및 목록 작성

원고: 甲(갑) 제1호증부터 순번 / 피고: 乙(을) 제1호증부터 순번. 서증목록에 번호·명칭·증명취지 기재.

💡 실무 TIP: 서증명칭은 실제 문서 제목과 일치시킬 것 — "계약서"가 아닌 "2023. 3. 1.자 부동산매매계약서"처럼 구체적으로

서증 사본 PDF 변환 및 전자소송 업로드

전자소송 제출 시 PDF 형식으로 변환. 파일명에 서증번호 포함. 원본은 기일에 지참.

문서제출명령·문서송부촉탁 신청 (필요 시)

상대방 또는 제3자(공공기관 등) 보유 문서가 필요한 경우 신청서 작성·제출.

💡 실무 TIP: 금융기관 거래내역 등은 문서송부촉탁(민소규 §121)으로 확보 가능

변론기일에 원본 지참 안내

전자소송으로 사본 제출하더라도 법원 요구 시 원본 제시 필요. 의뢰인에게 원본 보관·지참 안내.

6법무사 실무 노하우

💡 실무 TIP 모음

  • 서증목록 작성 시 증명취지를 간결명확하게 — "원고와 피고 간 2023. 3. 1. 부동산매매계약 체결 사실"
  • 사문서는 상대방이 날인을 인정하면 진정성립 추정 — 확인 서면 활용 가능
  • 내용증명우편 — 증명 부분(공문서) + 편지 내용(사문서) 혼합 문서임을 주의
  • 사본 제출 시 "원본과 틀림없음" 확인 문구 기재 권장
  • 금융 거래내역은 문서송부촉탁으로 법원이 직접 금융기관에 요청하도록 신청

7주의사항 & 사고 · 실수 사례

⚡ 기간도과 위험

  • 공문서 유효기간 — 3개월 초과 시 재발급 필요 (기관마다 상이)
  • 변론준비절차 종결 후 신규 서증 제출 실권효 위험

흔한 실수

  • 갑/을 서증 번호 중복 또는 순서 혼동
  • 사본 제출 후 원본 미지참으로 법원 확인 불가
  • 서증목록 증명취지를 "참조"로만 기재 — 구체적 사실 명시 필요
  • 내용증명 접수 도장 부분(공문서)과 편지 내용(사문서) 혼동
