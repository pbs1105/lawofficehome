사실조회 (조사·송부의 촉탁)

민사소송법 제294조, 민사소송규칙 제121조 / 법무사 업무: 사실조회신청서·문서송부촉탁 신청서 작성·제출 대행
사건유형: 민사소송 증거조사 단계 관할: 수소법원 근거법령: 민사소송법 제294조, 민소규 제121조 대상: 공공기관·법인·개인 핵심: 조사 대상 특정·회신 기간 추적

0⚠️ 법무사 업무범위 · 수임 판단

업무범위 한계

  • 가능: 사실조회신청서 작성·제출 대행, 문서송부촉탁 신청서 작성, 조회 대상 기관 정보 수집, 회신 결과 수령 및 의뢰인 전달
  • 불가(변호사법 위반): 조회 결과의 법적 의미 판단, 사실조회 결과를 활용한 소송전략 수립, 회신 거부 시 대응 방법 법률 조언

수임 판단 포인트

  • 사실조회는 특정 사항에 대한 조사를 촉탁하는 것 — 조회 사항이 구체적으로 특정되어야 함
  • 감정이 필요한 사항(전문가 판단)과 단순 사실 확인(사실조회)을 구분
  • 금융기관 거래내역 → 문서송부촉탁, 관공서 보유 사실 → 사실조회로 진행

받지 말아야 할 신호 체크리스트

  • "조회 결과가 어떤 의미인지 분석해주세요" — 법률 판단 요구
  • "조회 결과로 어떻게 주장해야 하나요?" — 소송전략 요구
  • 회신 거부 시 법적 대응 방법 문의 — 법률 조언에 해당

1핵심쟁점

실체적 쟁점 — 사실조회 vs 유사 제도 비교

제도내용근거특징
사실조회단체·개인에게 특정 사실 확인 촉탁민소 §294사실 확인 목적, 법원이 촉탁 주체
문서송부촉탁보유 문서를 법원에 송부 요청민소규 §121문서 자체를 서증으로 활용
감정촉탁전문기관에 전문적 판단 의뢰민소 §341법인·기관에도 가능, 전문지식 필요
문서제출명령당사자/제3자에게 보유 문서 제출 명령민소 §343강제력 있음, 불응 시 불이익

절차적 쟁점 (결정적 체크포인트)

  • 사실조회는 법원이 결정으로 발령 — 당사자 직접 조회 불가
  • 조회 대상 기관이 회신 거부 시 법원이 과태료 부과 가능 (민소 §294 후단)
  • 회신 결과는 서증으로 취급하지 않고 사실조회 결과로 별도 처리

2업무 절차 흐름

조회 사항 및 대상 기관 특정

의뢰인으로부터 확인이 필요한 사실과 해당 기관(금융기관, 관공서, 법인 등)을 특정받음. 기관명·주소·담당 부서 파악.

💡 실무 TIP: 조회 사항은 "○○○에 관한 사실을 조회합니다" 형식으로 구체적으로 특정 — 막연한 조회는 법원이 기각 가능

사실조회신청서 작성

조회 대상 기관, 조회 사항, 조회 필요성(증명취지) 기재. 대상 기관 수가 많으면 별지 목록 활용.

전자소송 제출 또는 법원 접수

신청서를 법원에 제출. 법원이 결정하면 직접 해당 기관에 조회서 발송.

회신 결과 모니터링

법원을 통해 회신 도달 여부 확인. 회신 지연 시 법원에 독촉 요청 가능. 회신 결과 의뢰인에게 전달.

문서송부촉탁 신청 (금융기관 등)

금융거래정보 등 문서 자체가 필요한 경우 문서송부촉탁 신청서 별도 작성. 기관명·문서 종류·기간 명시.

💡 실무 TIP: 금융기관 거래내역 — 은행명·계좌번호·기간 구체적 특정 필수

5법령 · 판례 검증

주요 근거 법령

✅ 민소 §294 — 조사의 촉탁(사실조회) ✅ 민소 §341 — 감정촉탁 ✅ 민소 §343 — 문서제출명령

주요 판례

대법원 1999. 7. 13. 선고 97다57979 — 소송 외 사감정서는 서증으로 제출 가능, 단 신뢰성 심사 필요 대법원 2010. 5. 13. 선고 2010다6222 — 일방 의뢰 사감정 신중 채용 원칙

6법무사 실무 노하우

💡 실무 TIP 모음

  • 사실조회 신청 시 조회 사항을 번호별로 나열 — 기관이 항목별로 답변하기 용이
  • 금융기관 조회는 문서송부촉탁이 더 효과적 — 거래내역 원문 자체를 서증으로 확보 가능
  • 회신 기간을 법원에서 지정하지 않으면 기관이 지연하는 경우 많음 — 법원에 기간 지정 요청 권장
  • 감정촉탁 vs 사실조회 구분 — 전문적 판단이 필요하면 감정촉탁, 단순 사실 확인이면 사실조회
  • 관공서 보유 행정정보(건축물대장·토지이용계획 등)는 사실조회 또는 서증 발급으로 확보
📝 현장 메모 [직접 추가]

자주 사실조회 신청하는 기관, 담당 부서, 평균 회신 기간, 특이 사례 등을 기록하세요.




7주의사항 & 사고 · 실수 사례

⚡ 기간도과 위험

  • 회신 지연으로 변론종결 전 결과 미도달 시 — 법원에 변론재개 신청 또는 기간 연장 요청 필요
  • 감정촉탁 비용 예납 지연 — 감정 절차 중단 가능

흔한 실수

  • 조회 사항이 지나치게 포괄적 — 법원 기각 또는 기관 회신 거부
  • 조회 대상 기관 주소·담당 부서 오기 — 조회서 반송
  • 사감정서(소송 외 감정)를 감정결과로 혼동 — 서증으로 제출하되 감정결과로 취급 금지

변호사법 경계선

  • 조회 결과의 법적 의미 분석 — 법률 조언에 해당
  • 회신 거부 시 과태료 신청 방법 조언 — 소송 관련 법률 조언
