민사조정 (조정신청·강제조정·소송이행)

민사조정법·민사조정규칙 / 법무사 업무: 조정신청서·이의신청서 작성·제출 대행, 인지보정 대행
사건유형: 민사분쟁 합의 절차 (ADR) 관할: 상대방 주소지·분쟁 목적물 소재지·손해발생지 등 관할 법원 근거법령: 민사조정법 / 민사조정규칙 담당: 조정담당판사 또는 조정위원회 핵심기간: 강제조정 결정 이의 2주 (불변기간)

0⚠️ 법무사 업무범위 · 수임 판단

업무범위 한계

  • 가능: 조정신청서 작성·제출 대행, 이의신청서 작성·제출 대행, 인지·송달료 납부 대행, 조정조서 기재 내용 확인 지원, 불성립 후 소송이행 시 인지보정 대행
  • 불가(변호사법 위반): 조정기일 출석·대리, 조정안 수락 여부 법리 판단, 소송전략 수립, 조정조서 내용의 법적 유불리 판단

수임 판단 포인트

  • 조정 대상인지 확인: 당사자가 자유로이 처분할 수 있는 권리에 관한 것이어야 함
  • 형성판결 효력이 필요한 사건(청구이의의 소), 회사관계소송(주총결의 무효·취소 등)은 인낙·인용형 조정 불가
  • 강제조정 결정 이의 의뢰: 결정서 정본 수령일 + 14일 이내인지 긴급 확인
  • 의뢰인이 조정안의 법적 유불리 판단을 원하면 변호사 연결

받지 말아야 할 신호 체크리스트

  • 강제조정 결정 이의 기간 2주 이미 도과한 경우
  • 당사자가 처분할 수 없는 권리가 관련된 사건에서 조정 성립 요구
  • 조정기일에 법무사가 당사자를 대신해 출석하도록 요구하는 경우
  • 조정안의 법적 유효성·법리적 타당성 판단을 법무사에게 요구하는 경우

1핵심쟁점

민사조정 vs 소송 — 수임 시 판단 기준

항목민사조정정식 소 제기
수수료(인지)소장 인지의 1/10 수준전액
처리기간빠름 (통상 조정기일 1~2회)수개월~수년
성립 조건양방 합의 필요불필요 (일방 청구)
불성립 시소송이행 + 인지 9/10 보정—
기판력있음 (재판상 화해 동일)있음
비공개조정기일은 비공개공개

조정 불가 사건 — 수임 전 반드시 확인

  • 형성판결 효력 필요 사건: 청구이의의 소처럼 집행력 배제 효과를 조정으로 만들 수 없음 (대법원 2023다256577)
  • 회사관계소송: 주주총회결의 무효·취소 등 제3자에게도 효력이 미치는 사건에서 인낙·인용형 조정 불가 (대법원 2004다28047)
  • 강행법규 위반 내용: 당사자가 처분할 수 없는 권리에 관한 합의는 조정으로 성립 불가

강제조정(조정을 갈음하는 결정) 핵심 체크포인트

  • 합의 불발 시 법원이 직권으로 발령 — 당사자 합의 없이도 법원이 결정
  • 결정서 정본 수령일로부터 2주 이내 이의신청 (불변기간)
  • 이의 없으면: 확정 → 재판상 화해와 동일한 효력 (= 확정판결과 동일)
  • 이의 있으면: 결정 효력 상실 → 소송절차로 이행

2업무 절차 흐름

① 조정 신청 측 절차

관할 법원 확인 → 조정신청서 작성

상대방 주소지·사무소·근무지, 분쟁 목적물 소재지, 손해 발생지 등 관할 법원. 서면 또는 말로 신청 가능. 수수료(인지) = 소장 인지의 약 1/10 수준. 청구취지·청구원인 기재 필수.

조정기일 — 당사자 출석 (법무사는 대리 불가)

당사자 본인이 출석해야 함. 법무사는 기일 출석 대리 불가. 조정위원회 또는 조정담당판사 주재. 비공개 진행. 상호 양보 권유.

💡 실무 TIP: 의뢰인이 기일에 준비할 사항 (증거서류, 희망하는 합의 조건 등)을 미리 정리해 드리는 것은 가능. 기일 전 충분히 상의.

[성립] 조정조서 작성 → 강제집행 준비

합의 성립 → 조정조서 작성 → 재판상 화해 효력 (= 확정판결과 동일). 상대방 불이행 시 별도 소송 없이 조정조서로 강제집행 가능. 조정조서의 집행문 부여 여부 확인.

[불성립] 강제조정 결정 or 소송이행

합의 불발 → 법원이 강제조정(조정을 갈음하는 결정) 발령 가능. 이의 없으면 확정, 이의 있으면 소송으로. 소송이행 시 신청인이 인지 나머지(9/10) 보정. 소 제기 시점 = 조정신청 시점.

② 강제조정 이의신청 절차 (피조정신청인 측)

결정서 정본 수령일 확인 → 2주 계산

수령일 다음 날부터 14일 계산. 말일 공휴일이면 익일로 연장. 이의 기간 내에 서면으로 이의신청 제출.

이의신청서 제출

이의 취지 기재. 이의 후: 결정 효력 상실 → 소송절차로. 소송 시 신청인이 인지 보정 의무.

③ 소송 중 조정회부 사건 대응

소송 중인 사건을 법원이 결정으로 조정에 회부할 수 있음 (항소심 판결 선고 전까지 가능).

조정 회부 → 조정 성립이면 소송 종료, 불성립이면 원래 소송으로 복귀.

소송 중 조정회부 사건은 별도 인지보정 없이 복귀.

4비용 · 소가 산정

조정신청 인지 계산

단계납부 인지비고
조정신청 시소장 인지의 약 1/10소가 기준 소장 인지 계산 후 1/10 납부
불성립 → 소송이행나머지 9/10 보정소 제기 시점 = 조정신청 시점으로 소급 적용

계산 프로그램: 대법원 인지계산기 활용 (민사조정 항목 선택)

※ 소가별 인지액 기준: 소가 1억 이하 → 소가×0.5% + 5,000원 등

소송이행 관할 주의

조정신청 소가가 2억 원 초과이면 소송이행 시 고등법원 또는 지방법원 합의부 관할 가능성 확인. 인지보정 완료 후 관할법원으로 기록 송부.

6법무사 실무 노하우

💡 강제조정 이의신청 기간 관리

  • 결정서 정본 수령 즉시 날짜 계산 → 의뢰인에게 마감일 서면으로 통보
  • 이의신청서 작성 후 법원 접수 확인 (전자소송 또는 직접 제출)
  • 이의 후 소송 이행: 신청인이 인지 9/10 보정 → 의뢰인이 채권자이면 보정 대행 준비

💡 조정신청서 작성 포인트

  • 청구취지: 원하는 합의 내용을 구체적으로 기재
  • 청구원인: 분쟁의 경위, 상대방의 의무, 합의를 원하는 이유 기재
  • 다투는 사정: 양방의 입장 차이 요약 — 조정위원이 파악하기 쉽도록

💡 조정조서 기재 확인

  • 조정 성립 시: 조정조서 내용이 집행 가능하게 특정되었는지 확인
  • 금전 지급: 금액, 이행기, 지연손해금 여부 명확히
  • 부동산 인도 등: 목적물 특정 (지번·면적 등), 도면 첨부 여부 확인
  • 의뢰인에게 조정조서 정본을 안전하게 보관하도록 안내

7주의사항 & 사고 · 실수 사례

⚡ 강제조정 이의신청 기간 도과 위험

  • 결정서 수령일을 의뢰인이 정확히 기억하지 못하는 경우 多 → 실물 확인 필수
  • 2주 경과 후 확정 → 집행력 발생 → 사후 다툼 불가
  • 수령 즉시 마감일을 계산하고 의뢰인에게 문자·서면으로 통보

흔한 실수

  • 조정 대상이 아닌 사건(형성판결 효력 필요, 회사관계소송 등)에 조정신청 → 각하 위험
  • 조정 불성립 후 인지보정 기간을 놓쳐 소송이행 불가
  • 조정조서에 이행기·금액이 불명확하게 기재 → 나중에 집행 불가
  • 법무사가 조정기일에 의뢰인을 대신해 출석 → 변호사법 위반

변호사법 경계선

  • 조정기일 출석·진술 대리 → 변호사법 위반
  • 조정안의 법적 유불리 판단·수락 권고 → 변호사 영역
  • 조정 불성립 후 소송전략 수립 → 변호사 영역
  • 법무사 가능 범위: 신청서 작성, 인지·송달료 납부, 이의신청서 작성, 인지보정 대행
