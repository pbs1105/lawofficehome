전자소송 당사자 자동입력

당사자(원고·피고·채권자·채무자) 정보를 전자소송포털 화면에 입력하고 [등록]까지 진행합니다. 최종 제출·전자서명은 자동화하지 않습니다.

에이전트 상태 확인 중…

내 PC의 자동입력 프로그램에 연결하는 중입니다.

작업 화면 열기

실행 순서

  1. 바탕화면의 전자소송 자동입력 시작(start-agent.bat)을 실행합니다.
  2. 자동으로 열리는 전용 Chrome 창에서 공동인증서로 로그인합니다. (평소 쓰는 Chrome과 별개입니다)
  3. 서류 작성 → 당사자 입력 화면까지 들어갑니다.
  4. 위의 작업 화면 열기를 누르고, 당사자를 입력한 뒤 승인합니다.
