A 즉답 카드

  • 한 문장 — 개인은 "앞으로도 계속 들어올 소득으로 생계비를 넘게 갚을 수 있는가"가 갈림길이다. 갚을 수 있으면 개인회생, 갚을 길이 없으면 개인파산을 먼저 본다. ● 답 ✓ 채무자회생법 제579조✓ 채무자회생법 제305조
  • 업무범위 — 사무소는 상담하고 개인회생·개인파산 신청을 대리한다. 법원 기일에서의 진술은 본인이 한다. 법인 사건은 서류 작성·제출 대행 범위로만 맡는다(S-C01). ● 답 ✓ 법무사법 제2조
  • 질문 여섯 개 — ① 누구의 빚인가 ② 소득이 계속 있는가 ③ 빚이 얼마인가 ④ 재산이 빚에 비해 얼마인가 ⑤ 최근 면책·신청 이력이 있는가 ⑥ 위험 신호가 있는가. ● 답
  • 한눈 비교 — 개인회생: 재산은 지키고 3~5년 소득으로 갚은 뒤 면책 / 개인파산: 재산을 정리하고 면책 / 신용회복위원회: 법원 밖에서 금융회사와 조정. ● 답 ✓ 채무자회생법 제580조✓ 채무자회생법 제611조✓ 신용회복위원회 「채무자 구제제도 비교표」
  • 고객이 꼭 묻는 세 가지
  • "회생이 나아요, 파산이 나아요?" → "소득과 재산, 빚이 생긴 이유에 따라 다릅니다. 오늘 여쭌 내용으로 법무사가 판단해 알려 드립니다." ▲ 법무사
  • "파산하면 불이익이 크지 않나요?" → 면책이 확정되면 복권되지만, 파산 면책 뒤 7년은 다시 면책받기 어렵고 세금·양육비 등은 남는다. ◐ 안내→법무사 ✓ 채무자회생법 제564조✓ 채무자회생법 제566조
  • "비용은 얼마나 드나요?" → 법원 비용은 채권자 10곳 기준 개인회생 약 54만원(외부 회생위원 사건이면 약 69만원), 개인파산 약 91만원(예납금 포함)이고, 법무사 보수는 견적서로 드린다. ● 답 (S-R01)
  • ✖ 말하면 안 되는 말 — ① "파산이 제일 간단합니다" ② "회생은 무조건 됩니다" ③ "상담 전에 급한 빚부터 갚고 오세요" ④ "재산은 가족 명의로 돌려 두세요"
  • 다음 페이지 — 업무범위·수임 S-C01 / 개인회생 S-I01(+계산 S-I03) / 개인파산 S-P01 / 법인 진단 S-B01 / 상담 시트 항목 S-R01 R-6
