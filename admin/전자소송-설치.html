전자소송 자동화 설치

직원 PC에 한 번만 설치합니다. 설치가 끝나면 바탕화면의 ECFS 콘솔로 매일 시작합니다.

설치 파일

버전
빌드일
파일
SHA-256
⬇ 설치 파일 받기 (Google Drive)
— 아직 다운로드 링크가 연결되지 않았습니다. 법무사에게 알려주세요.
Google Drive는 사무소 계정으로 로그인해야 받을 수 있습니다.

설치 순서 (약 15분)

  1. 위 버튼으로 zip 파일을 받습니다.
  2. 짧은 폴더를 만들고 그 안에 압축을 풉니다. 예: C:\ecfs\
    바탕화면·OneDrive 안처럼 경로가 긴 곳에 풀면 압축 풀기가 중간에 실패합니다.
  3. 받은 파일이 맞는지 확인합니다. zip이 있는 폴더에서 명령 프롬프트를 열고 아래를 실행한 뒤, 나온 값이 위 SHA-256과 같은지 봅니다. 
    4. 
      
  4. 푼 폴더 안의 install.bat을 더블클릭합니다.
    
        사건폴더 경로와 수신 담당 PC 여부를 물으면 답합니다. 모르면 법무사에게 물어보세요.
    5. 
      
  5. 설치가 끝나면 마지막 줄(설치 기록)을 복사해서 법무사에게 보냅니다.
    6. 
      
  6. 바탕화면 ECFS 콘솔을 엽니다. Chrome → 에이전트 → 콘솔 순서로 창이 뜹니다.
    
        Chrome에서는 공동인증서 로그인만 직접 합니다. 콘솔 상태등이 모두 켜지면 설치 끝입니다.
    7. 
      
  7. 이후에는 admin 메뉴 제출 → 전자소송 콘솔에서도 같은 콘솔을 쓸 수 있습니다(에이전트는 켜져 있어야 합니다).
    
        admin 안에서 처음 열 때 콘솔 위에 토큰 입력줄이 보이면, 에이전트 창에 찍힌 토큰을 한 번 넣습니다(이 PC에서 1회).
    8. 
    

  


  

    
알아둘 것

    
    
      
  • 에이전트 창(검은 창)은 작업 중에 닫지 않습니다. 닫으면 입력이 중간에 멈춥니다.
    • 
      
  • 새 버전이 나오면 이 페이지의 버전이 바뀝니다. 새 zip을 같은 방법으로 받아 교체합니다(자동 업데이트 없음).
    • 
      
  • 최종 제출·전자서명은 자동화하지 않습니다. 임시저장까지만 진행합니다.
