Notion 사건 정보를 바탕으로 ecfs.scourt.go.kr 소장 작성 화면(전자소송 동의 → 사건기본정보 → 당사자 → 청구취지·이유 → 소명서류 → 임시저장)을 자동으로 채웁니다.
⚠️ 실제 전자소송포털에 데이터가 입력됩니다.
이 화면은 사무실 PC에서 실행 중인 로컬 자동화 서버(http://localhost:3939)를 호출해, 직원이 인증서로 이미 로그인해 둔 실제 Chrome 화면을 직접 조작합니다. 최종 [등록] 클릭 전자서명·제출은 이 자동화가 절대 하지 않지만, 당사자 정보·신청취지 등은 실제 화면에 그대로 입력됩니다. 반드시 실행 전 아래 내용을 확인하고, 실행 후에는 포털 화면에서 입력 내용을 직접 검토·제출하세요.

사전 준비: ① 사무실 PC에서 2_start_chrome_debug.bat로 연 Chrome에 인증서로 로그인 ② 3_start_server.bat(또는 Windows 서비스)로 자동화 서버 실행.
⚙️ 연결 설정 (자동화 서버 주소)
사무실 PC가 아닌 다른 PC에서 이 화면을 열었다면, 자동화 서버가 실행 중인 PC의 주소(예: http://192.168.0.10:3939)로 바꾸세요.
