🏠 부동산 실거래 신고서 작성기 n8n · 노션 연동

매매계약서(.docx) → n8n 웹훅으로 노션 자료 보강 → 검증 → 신고서(별지 제1호서식) 문서 생성까지, 브라우저에서 바로 실행합니다.

이 도구가 하는 일: 신고서 문서 작성까지입니다. RTMS(rtms.molit.go.kr) 접속·전자신고·전자서명·제출은 하지 않습니다. 작성된 신고서는 법무사가 검토한 뒤 직접 RTMS 전자신고 또는 관할 시·군·구에 제출합니다.
⚙️ 연결 설정 (웹훅 주소 · 시크릿)

STEP 2의 "노션에서 불러오기"가 사용하는 n8n 웹훅입니다. 기본값이 채워져 있으며, 필요 시 수정 후 설정 저장을 누르면 이 브라우저에 기억됩니다.

1 매매계약서 불러오기

매매계약서 자동생성기가 만든 .docx 파일을 업로드하세요. 파일이 없으면 샘플이나 빈 양식으로 시작할 수 있습니다.

2 노션 DB에서 값 불러오기 (n8n 웹훅)

계약서만으로 채워지지 않는 값(부동산 고유번호·면적·지목·지분, 당사자 등록번호·주소 등)을 n8n 웹훅을 통해 노션에서 직접 조회해 채웁니다. 사건번호를 입력하고 "노션에서 불러오기"를 누르세요. 조회된 값은 원본대조 전이므로 미검증으로 표시되며, STEP 3에서 대조 후 확정합니다.

고급 · 불러온 JSON 보기 / 직접 편집

웹훅이 반환해 반영한 값입니다. 직접 수정한 뒤 "보강 적용"으로 다시 반영할 수 있습니다. 검증:"검증완료"이면 자동 확정되고, "미검증"이면 원본대조 표시가 유지됩니다.

3 검증 체크리스트 — 원본대조

값을 직접 수정할 수 있고, 등기부·대장·신분증 등 원본과 대조를 마친 항목은 "대조완료" 체크박스를 눌러 확정하세요. 체크되지 않은 원본대조 필요 항목은 신고서에 노란색으로 표시됩니다.

⚠️ 원본대조가 필요한 항목이 0건 남아 있습니다.
필드(신고서 표기명)값소스상태대조완료

4 신고서 문서 생성

부동산거래계약 신고서(별지 제1호서식) 형태로 문서를 만듭니다. 검토·인쇄·저장 후 법무사가 직접 신고에 사용하세요.

신고기한: 계약체결일부터 30일 이내 · 근거: 「부동산 거래신고 등에 관한 법률」 제3조 / 시행령 제3조·별표1 / 시행규칙 제2조·별지 제1호서식.
서식·자금조달 기준·규제지역은 개정이 잦으니, 신고 전 국토교통부 부동산거래관리시스템(rtms.molit.go.kr)에서 최신 기준을 확인하세요.
STEP 2의 "노션에서 불러오기"는 n8n 웹훅(인터넷)을 사용하며, .docx 파싱에는 JSZip 라이브러리(cdnjs) 로딩을 위해 인터넷 연결이 필요합니다. 웹훅 조회 시 사건번호와 시크릿만 전송되고 노션 값을 응답으로 받습니다.
